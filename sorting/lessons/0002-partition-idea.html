The partition idea: quicksort and quickselect

The exam’s other sorting item is one technique question: which quicksort idea does quickselect use? This lesson pins the pivot-and-partition loop, the exam’s verbatim explanation, and the one difference between the two algorithms, then drills the sentence until it comes out whole.

Why this lesson

Lesson 1 settled the identification half: counting sort counts, it never compares. This lesson is the technique half: quicksort and quickselect compare everything to a pivot. The exam asks what quickselect borrows from quicksort and expects one explanation - this lesson attaches that explanation to the four steps.

Quicksort: pick a pivot, partition

Quicksort’s core idea is two moves. Pick a pivot - one element of the list. Partition - rearrange so everything below the pivot sits on one side and everything above sits on the other. Then sort each side the same way:

list:     [7, 2, 9, 4, 6]   pivot 6
partition: [2, 4]  6  [7, 9]
then:      sort [2, 4] and sort [7, 9]

The core idea, one line

Quicksort picks a pivot and partitions the list into elements below and above the pivot. The partition step is the idea quickselect borrows.

Quickselect: find a rank, sort nothing

Quickselect answers a different question: what is the kth smallest or kth largest element - without sorting the entire list. It reuses the partition step and then follows only one side. The exam’s four steps, in order:

  1. Choose a pivot.
  2. Partition elements into those below and above the pivot.
  3. Determine which partition could contain the desired rank.
  4. Continue only in that relevant partition.

Step 3 is the trick: the partition’s size tells you where the rank lives. If you want the 2nd smallest and the below-pivot partition holds four elements, the answer is inside it - the other side is discarded.

The exam’s explanation, verbatim

Quickselect uses partitioning to partition the list and focus on the relevant section.

The one difference: one side, not both

Quicksort sorts, so it must finish both partitions - the full list has to end up ordered. Quickselect wants one rank, so it needs only the partition holding it. The exam asks the difference directly:

The exam’s contrast, verbatim

Unlike quicksort, quickselect does not recursively sort both partitions. One side is followed; the other is dropped. That is what “without sorting the entire list” means.
