# Sorting and Selection Resources

## Knowledge

- Local file: `~/school/c949/C949_Data_Structures_and_Algorithms_1_Study_Guide.md` (outside this repo)
  The practice exam content. Ground truth for what C949 asks. Use for: scoping every lesson to exam question types.
- Book: _Introduction to Algorithms_ (CLRS) - Cormen, Leiserson, Rivest, Stein
  Chapter 8 covers counting sort and the O(N + K) analysis; Chapter 7 covers quicksort and the partition step; Chapter 9 covers quickselect (order statistics). Use for: settling any dispute about the complexity or the partition idea.
- [algs4: Section 2.3, Quicksort (Sedgewick & Wayne, Princeton)](https://algs4.cs.princeton.edu/23quicksort/)
  The canonical treatment of pivoting and partitioning. Use for: lesson 2's partition vocabulary.
- [Wikipedia: Counting sort](https://en.wikipedia.org/wiki/Counting_sort)
  The reference overview of the counts array and the practicality condition. Use for: the O(N + K) definition and the K-versus-N check.
- [Python HOWTO: Sorting](https://docs.python.org/3/howto/sorting.html)
  The official Python treatment of sorting; useful background if a question mixes sorting with Python code. Use for: sorting vocabulary in a Python context.
