The stack

A stack follows LIFO: last in, first out. One open end, the top; everything enters and leaves through it.

  • push(x) - add x on top of the stack.
  • pop() - remove and return the top item.
  • top() - read the top item without removing it.

The last item pushed is the first item popped. Think of a stack of cafeteria trays.

The queue

A queue follows FIFO: first in, first out. Two ends, two jobs: items enter at the back, leave at the front.

  • enqueue(x) - add x at the back.
  • dequeue() - remove and return the front item.
  • front() - read the front item without removing it.

The back computation

Given [72, 15, 2, 14], front_index = 0, length = 4: the front is the element at front_index (72), and the back is the last active element - index front_index + length - 1 = 3 (14). The front and the back are opposite ends.
