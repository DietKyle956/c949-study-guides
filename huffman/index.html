Huffman coding

A short course on the exam’s last content topic: lossless compression with variable-length binary codes, shorter codes handed to the more frequent characters, and the lower average bits per character that makes the file smaller. One lesson teaches the idea, then drills recognition with a quiz.

Reference

The Huffman card - every Huffman row and its answer on one printable page, with the two verbatim sentences in one place. Keep it open while drilling until recognition is automatic.

Outside resources

  • CLRS: Introduction to Algorithms (MIT Press) - the canonical text; Chapter 16.3, Huffman Codes, derives the shorter-codes-for-frequent-characters rule.
  • Wikipedia: Huffman coding - the reference overview of lossless compression and the variable-length code idea.
