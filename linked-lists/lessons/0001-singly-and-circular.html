Linked lists · Lesson 1

Singly and circular lists: the reference update

The exam gives you a linked-list moment - removing the first node, or a list that never ends - and asks what update does it. This lesson maps each moment to its one-line answer, then drills the recognition until it is instant.

Why this lesson

You already know the big idea from the ADTs course’s arrays vs linked structures lesson: arrays shift, linked structures update references. This lesson makes the update concrete. Two of the exam’s rows live here: removing the first node of a singly linked list (head = head.next) and the circular list that cycles without an end. Both become free points once the update is automatic.

The node and the head

A singly linked list is a chain of nodes. Each node stores two things: a value and a next reference pointing to the following node. The last node’s next reference is None - the end of the chain.

head -> [ 10 | * ] -> [ 20 | * ] -> [ 30 | * ] -> None

The only way in: the head

The list keeps one reference to the first node, called head. Every other node is reached by following next references from it. There is no indexing - node 30 is not “at position 2”, it is two hops from head.

Removing the first node

The exam’s singly linked list question is exactly this: to remove the first node, update the head reference:

head = head.next
Before: head -> [ 10 | * ] -> [ 20 | * ] -> [ 30 | * ] -> None
After:  head -> [ 20 | * ] -> [ 30 | * ] -> None

What the update does, in the exam’s words

It updates the reference to point to the next node in sequence. The first node is simply skipped over - nothing moves, nothing shifts.

The contrast to keep in your head: removing the first item of an array shifts every later element one position left. Removing the first node of a linked list changes one reference. The exam even says it: no nodes need to be shifted, because linked-list nodes are connected by references.

The circular list: no end to reach

In a circular linked list, the final node’s next reference points back to the first node instead of None. There is no end of the chain:

head -> [ A | * ] -> [ B | * ] -> [ C | * ] -+
        ^                                    |
        +------------------------------------+

The exam’s two circular answers

Definition: the final node points back to the first node rather than to null or None.

Use for a repeating process: by continuously cycling through nodes without reaching an end. The exam’s example is round-robin scheduling - give each process a turn, then start the cycle again.
