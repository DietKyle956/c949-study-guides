The singly linked list

Nodes hold a value and a next reference. The only way in is head; the last node’s next reference is None.

Removing the first node

head = head.next - it updates the reference to point to the next node in sequence. One reference changes; no node shifts. Contrast: removing the first item of an array shifts every later element left.

The circular list

The final node’s next reference points back to the first node rather than to null or None. Use for a repeating process: by continuously cycling through nodes without reaching an end - the exam’s example is round-robin scheduling.

The doubly linked list

Each node stores a value and two references: next and prev. A positional list is commonly implemented as a doubly linked list.

The four-link insertion

Inserting a new node between A and B:

A.next     -> new
new.prev   -> A
new.next   -> B
B.prev     -> new

Each node stores links to its previous and next neighbors and needs only pointer updates. Nothing shifts.

The exam tip

From the study guide’s strategy list: for linked lists, think in terms of reference updates; for arrays, think in terms of indices and potential shifting. Whichever structure the question names, that one line picks the right mental model.
