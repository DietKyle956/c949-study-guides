# Mission: ADTs and Linear Structures

## Why
Pass the C949 assessment questions on abstract data types and linear structures. These are identification questions - the exam gives a one-line description and asks you to name the concept. The user wants each defining property ("what, not how", "named subitems", "index vs reference") mapped to its answer so these become free points.

## Success looks like
- Given "specifies what operations are supported without revealing the implementation", the user answers ADT immediately.
- The user states the exam's ADT benefit answer ("focus on higher-level operations and algorithms") from memory.
- Given "stores subitems with a name associated with each subitem", the user answers Record.
- The user can name a record's subitems as fields and distinguish records (by name) from arrays (by position).
- The user states the array-vs-linked tradeoff: arrays index directly but shift on middle insert/remove; linked structures update references instead.
- Every ADT-related question in the practice exam is answered without notes.

## Constraints
- Simplest possible methods - definitions and recognition, no implementation projects.
- Learning happens in short sessions; lessons must be completable in one sitting.
- Lessons must work offline and print cleanly for revision.
- Workspace lives at ~/school/c949/study_guides/adts and is published on GitHub Pages as part of the c949-study-guides site.
- Reuses the shared stylesheet and quiz widget from the Big O workspace - same look, same interaction.
