ADTs and linear structures · Lesson 2

Arrays vs linked structures: index or reference

One question keeps coming back on the exam: which structure matches this description? Two defining properties settle every version of it - arrays index directly but shift when the middle changes; linked structures update references but walk from the head. This lesson maps the tradeoff, then drills the recognition.

Why this lesson

The exam does not ask you to build either structure. It describes one and asks which it is, and its own exam-approach section names the two mental models: “for linked lists, think in terms of reference updates; for arrays, think in terms of indices and potential shifting.” That sentence is this whole lesson - plus the one cost each structure pays that the tradeoff questions test.

Arrays: index into anything, pay to move the middle

The exam’s wording: arrays usually offer direct index access, but inserting or removing in the middle can require shifting items.

[a, b, c, d]        insert X at index 1
[a, X, b, c, d]     b, c, d each shift right one slot

Array mental model: indices and shifting

An index is a direct address calculation - reach any element in one step, O(1), like the array-index row on the Big O cheat card. The price: elements sit in contiguous slots, so changing the middle means every later element moves.

Linked structures: pay to find, move for free

The exam’s wording: linked structures store nodes connected by references. Once the target location is known, insertion or removal typically involves updating references rather than shifting every later element.

a -> b -> c -> d          insert X after a
a -> X -> b -> c -> d       two references change; b, c, d never move

Linked mental model: reference updates

Each node points to the next, so a middle insertion only rewrites the arrows near the spot - no shifting. The price is the other half of the tradeoff: there is no index, so reaching a node means walking from the head, one node at a time - O(n) in the worst case.

Recognition is one check: does the description mention walking from the head, or updating references? Linked. Does it mention indexing or shifting? Array. Each phrase maps to exactly one structure - that is the whole question type.
