# ADTs and Linear Structures Resources

## Knowledge

- Local file: `~/school/c949/C949_Data_Structures_and_Algorithms_1_Study_Guide.md` (outside this repo)
  The practice exam content. Ground truth for what C949 asks. Use for: scoping every lesson to exam question types.
- [algs4: Section 1.3, Bags, Queues, and Stacks (Sedgewick & Wayne, Princeton)](https://algs4.cs.princeton.edu/13stacks/)
  The canonical university treatment of ADTs: data types defined by their API - what operations exist, independent of how they are implemented. Use for: the ADT idea and the interface/implementation split.
- [GeeksforGeeks: Abstract Data Types](https://www.geeksforgeeks.org/abstract-data-types/)
  A short, exam-level definition of ADTs ("what a data structure does without dictating how"). Use for: an alternative phrasing when the what/how distinction does not click.
- Book: _Introduction to Algorithms_ (CLRS) - Cormen, Leiserson, Rivest, Stein
  Chapter 10 covers elementary data structures and the array vs linked structure tradeoff (indexing vs reference updates). Use for: the lesson 2 comparison and settling any dispute about definitions.
- [Wikipedia: Record (computer science)](https://en.wikipedia.org/wiki/Record_(computer_science))
  The record concept: related values stored as named fields (struct, tuple, row). Use for: the named-subitems definition in lesson 1.
