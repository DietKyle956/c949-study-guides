# Python Foundations Resources

## Knowledge

- Local file: `~/school/c949/C949_Data_Structures_and_Algorithms_1_Study_Guide.md` (outside this repo)
  The practice exam content. Ground truth for what C949 asks; its section 2, _Python Foundations_, is this workspace's source. Use for: scoping every lesson to exam question types, and for the verbatim sentences quoted in the rule boxes.
- [The Python Tutorial (docs.python.org)](https://docs.python.org/3/tutorial/)
  The official tutorial. Section 3 introduces the operator ladder with worked expressions; section 5 covers lists, tuples, and slicing; its sorting section states the `sorted()` versus `.sort()` contrast. Use for: the canonical explanation behind every lesson.
- [The Python Language Reference (docs.python.org)](https://docs.python.org/3/reference/)
  The exact rules: operator precedence in the expressions chapter, and identifier grammar with the reserved keyword list in the lexical analysis chapter. Use for: settling any dispute about what is valid Python.
- [Python HOWTO: Sorting](https://docs.python.org/3/howto/sorting.html)
  The official page devoted to sorting: `sorted()` returns a new list, `.sort()` returns `None`. Use for: lesson 3's contrast, with the docs' own wording.
- Book: _Python Crash Course_ (Eric Matthes)
  A gentle, exercise-driven path through the same basics. Use for: a slower re-entry if one of the lessons lands flat - not needed for the exam rows themselves.

## Wisdom (Communities)

- [r/learnpython](https://reddit.com/r/learnpython)
  Beginner-focused forum with patient answers. Use for: "why is this name invalid" or "why did this loop stop" questions.
- [Stack Overflow, python tag](https://stackoverflow.com/questions/tagged/python)
  Use for: the exact wording of error messages, such as why an assignment into a tuple fails.
