Precedence and identifiers

The exam’s Python block opens with two small questions: which operation runs first inside one expression, and which names are legal Python. This lesson pins the precedence ladder, walks the exam’s exact expression step by step, and drills the four identifier rules with their three invalid examples.

The precedence ladder

Precedence means which operator goes first when several sit in one expression. The exam only tests four tiers, always in this order:

  1. ** exponentiation
  2. *, /, //, %
  3. +, -
  4. Comparisons such as ==

Read the ladder as a race the tiers run in order: every ** finishes before any multiplication or division, those finish before any addition or subtraction, and only then does the comparison run. Nothing in this exam needs parentheses, but parentheses are how you prove you know the order.

The exam’s sentences, verbatim

In X / 2 + Y ** 2 == 10, the first operation is Y ** 2. Python evaluates exponentiation before division, addition, and equality comparison.

Order of the relevant operators: ** exponentiation; then *, /, //, %; then +, -; then comparisons such as ==.

The exam’s expression, worked

Here is the expression exactly as the exam writes it:

X / 2 + Y ** 2 == 10

Python’s own grouping of it - the same expression with the precedence made visible:

(X / 2 + (Y ** 2)) == 10

The four steps, in the order they happen:

  1. Y ** 2 - the exponentiation tier runs first, before anything else touches it.
  2. X / 2 - the * / // % tier runs second.
  3. X / 2 + (Y ** 2) - the + - tier runs third, adding the two results.
  4. ... == 10 - the comparison runs last and produces True or False.

The exam asks only the first step. Read the expression, find the **, and answer Y ** 2 - not X / 2, which runs second, and not the comparison, which runs last.

Identifiers: the four rules

An identifier is a name you give a variable, function, or class. The exam asks which names are legal. Four rules decide every case:

  • Can use letters, digits, and underscores.
  • Cannot begin with a digit.
  • Cannot contain a hyphen.
  • Cannot be a reserved keyword.

The study guide’s examples, verbatim:

my_variable

class          # Reserved keyword
my-variable    # Hyphen is interpreted as subtraction
2ndVariable    # Cannot start with a digit

One valid, three invalid, and each invalid one breaks a different rule. my-variable is the trap: Python does not see one name, it sees the subtraction my - variable. The hyphen is an operator, never part of a name.

The exam’s rule, verbatim

A Python identifier can use letters, digits, and underscores, cannot begin with a digit, cannot contain a hyphen, and cannot be a reserved keyword. The exam’s valid example is my_variable; the invalid examples are class, my-variable, and 2ndVariable.
