Precedence

The exam’s expression is X / 2 + Y ** 2 == 10, grouped by Python as (X / 2 + (Y ** 2)) == 10.

The exam’s sentences, verbatim

The first operation is Y ** 2. Python evaluates exponentiation before division, addition, and equality comparison.

Tiers, in order: ** exponentiation; *, /, //, %; +, -; comparisons such as ==.

Identifiers

The exam’s rules, verbatim

A Python identifier can use letters, digits, and underscores, cannot begin with a digit, cannot contain a hyphen, and cannot be a reserved keyword.

Valid: my_variable. Invalid: class (reserved keyword), my-variable (hyphen is interpreted as subtraction), 2ndVariable (cannot start with a digit).

Lists, tuples, and slicing

Mutability and the slice, verbatim

Lists are mutable; tuples are immutable. A list can add, remove, or replace elements - items[0] = 9 is valid; a tuple cannot - coordinates[0] = 9 is an error.

my_list[start:end] creates a new list containing some elements from another list. The starting index is included. The ending index is excluded. my_list[index] returns one element, not a list, and my_list.pop() removes and returns an element.

my_list = [10, 20, 30, 40]
index        0   1   2   3
my_list[1:3]  ->  [20, 30]

sorted() versus .sort()

The two calls, verbatim

sorted(my_list) returns a new list containing the elements in sorted order and leaves the original list unchanged. my_list.sort() sorts the existing list in place and does not return the sorted list.

The sample loop

total = 0
count = 0
for i in range(1, 11):
    if i % 5 == 0:
        break
    total += i * 2
    count += 1
average = total / count
print("Average:", average)

The trace, verbatim

The loop processes 1, 2, 3, 4 and stops before processing 5. total = 2 + 4 + 6 + 8 = 20, count = 4, average = 20 / 4 = 5.0. Output: Average: 5.0

Overloaded methods

The definition, verbatim

Overloaded methods have the same name, different parameter lists.

The exam tip

From the study guide’s strategy list: identify the defining property in the question. “First operation in the expression” - Y ** 2. “Can it change after creation?” - mutable list, immutable tuple. “Returns a new list” - sorted(); no return - .sort(). “Same name, different parameter lists” - overloaded.

The same list adds, for code tracing: write down values after each iteration and carefully note conditions such as break. That habit is what turns the sample loop into Average: 5.0 instead of a guess.
