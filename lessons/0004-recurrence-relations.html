Big O for Exams · Lesson 4

Recurrence relations: levels for any shrink

Exam writers love one question shape: given T(N) = N + T(N − 8), how many levels does the recursion have? One division answers every version of it - and the same count feeds the time and space answers you already know how to state.

Why this lesson

Lessons 1 and 2 taught two shrinks: minus one (n levels) and divide by half (log n levels). The exam generalizes both: subtract any constant, divide by any factor, and ask for the number of levels directly. This lesson turns the general case into one mechanical rule, then shows that everything else is the Lesson 2 formula, time = work per level × levels, wearing a new outfit.

The exam’s own words for this family of questions, from the C949 practice exam: “How many levels does T(N) = N + T(N − 8) have?” and “Which of these is a recurrence relation?” Both become free points after this lesson.

What a recurrence relation is

The exam definition: a recurrence relation defines a function using earlier or smaller instances of itself. That is the whole definition - the only thing you check is whether the function’s own name appears on the right-hand side.

f(n) = f(n - 1) + 2      # recurrence: f is defined via f(n - 1)
f(n) = n * n + 2 * n     # closed form: no self-reference, just arithmetic

Recognition is the exam’s “identify the defining property” question: if the right side calls the function itself on a smaller input, it is a recurrence. If not, it is a closed form.

Read a recurrence as a two-part plan

T(N) = N + T(N − 8) says: do N work, then call yourself on N − 8. The left part is the work per level. The right part is the shrink. Keep the two numbers separate - mixing up the work and the shrink is the classic wrong answer on this topic.

The one rule: divide N by the shrink

Levels are just the list of input sizes from the first call down to the base case. Write the first three sizes; the pattern between them tells you which rule to use.

Subtract a constant k: levels = N / k

N, N − k, N − 2k, ... The gap between neighboring levels is k, and the sizes travel distance N in steps of k: N / k levels (more exactly ceil(N / k) when N is not a multiple of k - the exam answers N / k).

Divide by a factor b: levels = logb N

N, N / b, N / b², ... The size multiplies its denominator by b each level, so the number of levels is logb N. Since any log base differs only by a constant, this is simply O(log N).

The two shrinks you already know are special cases of these rules: minus one is k = 1, giving N / 1 = N levels (factorial, Lesson 2); divide by half is b = 2, giving log₂ N levels (binary search, Lessons 1 and 2).

The first-three-sizes trick

Never guess from the code’s look. Write N and the next two sizes:

N, N - 8, N - 16    equal gaps    -> subtraction -> levels = N / 8
N, N / 2, N / 4     equal ratios  -> division    -> levels = log N

Equal gaps mean subtract; equal ratios mean divide. Then apply the matching rule.

Worked example: T(N) = N + T(N − 8)

The exam’s own question. Apply the trick:

T(N) = N + T(N - 8)
sizes: N, N - 8, N - 16, ...
gaps of 8, so levels = N / 8   (more exactly ceil(N / 8))

Levels: N / 8. That is the answer the exam wants. If the question goes one step further and asks for the whole complexity, the same count finishes the job:

  • Time: each level does at most N work, and there are N / 8 levels: N × N / 8 = O(N²). The exact sum N + (N − 8) + (N − 16) + ... lands on the same O(N²).
  • Space: the stack holds one chain of pending calls, and the chain is N / 8 levels deep: O(N) (the Lesson 3 rule: space = levels).

The trap: the prefix sets the work, the shrink sets the levels

T(N) = 1 + T(N - 8)     # levels still N / 8, but O(1) work each

Same shrink, smaller prefix: N / 8 levels × O(1) work = O(N), not O(1) and not O(N²). The two numbers in the recurrence are independent knobs - turn them one at a time.

Divide by any b: binary search and friends

The exam states binary search’s recurrence directly: T(N) = T(N / 2) + O(1) - halve the range, O(1) work per call. Log₂ N levels × O(1) = O(log N).

Any divisor works the same way. T(N) = T(N / 3) + O(1) has log₃ N levels, still O(log N), because log₃ N = log N / log 3 and the denominator is a constant. This is the same reason a loop with i = i × 3 was O(log n) in Lesson 1: the base never matters, only that the input keeps dividing.

The 60-second procedure

  1. Write the first three input sizes - N, then the next two sizes the recurrence produces.
  2. Pick the rule. Equal gaps: subtract k, levels = N / k. Equal ratios: divide by b, levels = logb N.
  3. Only if asked for more than levels: time = work per level × levels (Lesson 2); space = levels, the stack (Lesson 3).

The exam usually asks for levels directly - answer with the count. Your mission’s questions ask for Big O - the same three steps answer both, because every answer grows out of the level count.
