Why this lesson

Lessons 1 through 4 each drilled one skill in isolation, which is how skills are built. The exam is the reverse: one question asks for a simplification, the next for a stack depth, with no hint about which rule to reach for. Recognizing which rule applies is itself the skill this lesson drills - that is interleaving, and it is the difference between knowing each rule and using the right one under exam conditions.

The exam-day procedure

Three moves, in order, straight from the practice exam’s own approach section:

  1. Identify the defining property in the question - recurrence? nested loops? auxiliary space? That tells you which lesson’s rule applies before you compute anything.
  2. Remove constants and lower-order terms, then choose the dominant growth rate. O(855N) is O(N); O(12N + 7N + 500) is O(N).
  3. Trace the code - write the values after each iteration, and watch break, return, and the loop bounds. Guessing at a loop is how exams earn their wrong answers.

    odds = []
    for n in numbers:
        if n % 2 != 0:
            odds.append(n)
