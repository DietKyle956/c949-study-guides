The exam-day card

The five moves from the course’s exam-approach playbook plus the Big O names, on one printable page.

The five moves

  1. Identify the defining property - FIFO or LIFO? mutability? named fields? recurrence? partitioning? Name it before computing anything.
  2. Rule out choices describing a different ADT or algorithm.
  3. For Big O: drop constants and lower-order terms, keep the dominant term.
  4. For code tracing: write the values after each iteration; watch break, return, and the loop bounds.
  5. For linked lists think reference updates; for arrays think indices and shifting.
