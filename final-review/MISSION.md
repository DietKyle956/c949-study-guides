# Mission: Final Interleaved Review

## Why
The topics are taught; what remains is transfer. The C949 assessment shows similar-but-different versions of the drilled questions, so the user needs practice recognizing which rule applies when nothing is labeled. This review builds that with two 40-question practice tests whose questions repeat nothing from the lessons or the practice exam.

## Success looks like
- The user scores 36 or more out of 40 on each practice test from memory, no notes.
- For every miss, the user names the topic and the rule that answers it before looking at the explanation.
- Each test is completed in one sitting, at roughly two minutes per question.
- After redoing test 1 two days later and test 2 the morning of the exam, the user walks in treating every exam question as a familiar shape.

## Constraints
- No question may repeat any of the 127 lesson questions or the 30 practice-exam items - new numbers, new snippets, new phrasing, new angles.
- Simplest possible methods - exam-speed recognition, no implementation projects.
- Learning happens in short sessions; each test must be completable in one sitting or printable.
- Lessons must work offline and print cleanly for revision.
- Workspace lives at ~/school/c949/study_guides/final-review and is published on GitHub Pages as part of the c949-study-guides site.
- Reuses the shared stylesheet and quiz widget from the Big O workspace - same look, same interaction.

## Out of scope (for now)
- New topic content - every topic already has its own course.
- Rewriting the quiz widget (shuffling, persistence, resets).
- Exam content beyond the practice exam&rsquo;s scope.
