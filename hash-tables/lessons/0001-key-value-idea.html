The definition: keys to values

A hash table maps keys to values. You hand it a key, it hands back the value stored under that key. The exam’s own example, in Python:

hash_table = {}
hash_table["apple"] = 5
hash_table["banana"] = 3
hash_table["cherry"] = 8

The defining property

A hash table maps keys to values. That one line is the identification answer: any question asking which structure maps keys to values is answered hash table.

The two operations: store and retrieve

The exam shows both lines, so read them as a pair. Storing:

hash_table["apple"] = 5

puts the value 5 under the key "apple". Retrieving:

hash_table["apple"]

gives 5 back. The same key that stored the value is the key that fetches it.

How to read the line

hash_table["apple"] = 5 - the key goes in the brackets on the left, the value goes on the right of the equals. Retrieval is the same brackets with no equals: the key in, the value out.

Position vs key

The exam likes one contrast here. A list or array is reached by position: items[2] means the third item. A hash table is reached by key: hash_table["apple"] means “whatever value is stored under the key apple” - the key replaces the index.

The exam’s contrast, one line

Lists look up by numeric index; hash tables look up by key.
